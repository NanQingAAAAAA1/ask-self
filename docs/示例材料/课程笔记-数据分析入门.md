# 数据分析入门 · 第 3 讲（示例材料）

> 虚构示例，用于演示「非日记材料整篇成卡」。

## 描述性统计

均值对极端值敏感，中位数更稳健。判断一组数据该用哪个，先看分布是否偏斜——先画直方图，再决定用哪个统计量，不要一上来就算平均数。

四分位距（IQR）用来找异常值：低于 Q1-1.5×IQR 或高于 Q3+1.5×IQR 的点标为疑似异常，但要回到原始记录确认是不是录入错误。

## 相关性不是因果

相关系数只说明同向或反向变动，不说明谁导致谁。经典的坑：冰淇淋销量和溺水人数正相关，真正的原因是气温。

## 练习记录

用一份 3 万行的订单表做了分组聚合，发现周末客单价略高但订单数少。老师提醒：先确认时区字段是否统一，否则周末会被切错。

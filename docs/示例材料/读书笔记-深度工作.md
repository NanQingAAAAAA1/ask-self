# 《深度工作》读书笔记（示例材料）

> 虚构示例，用于演示收藏类文章整篇成卡。

核心论点：高质量产出 = 时间 × 专注强度。大部分人只增加时间，不提升强度，所以越忙越没成果。

## 三个可落地的做法

1. **固定时段**：每天留一段 90 分钟不被打断的时段，提前一晚写好这段要解决的具体问题。
2. **仪式感**：开工前清桌面、关消息、放一杯水，用固定动作提示大脑进入状态。
3. **收工仪式**：结束时写下「卡在哪、下一步做什么」，第二天不用重新加载上下文。

## 我的疑问

书里的例子里几乎都是可以自主安排时间的人。对于会议多、被打断频繁的岗位，这套方法要怎么改造？初步想法是把深度时段压到上班前，把碎片时间专门用来处理沟通。

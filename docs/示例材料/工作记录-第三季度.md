# 第三季度工作记录（示例材料）

> 虚构示例，用于演示「工作记录整篇成卡 + 无日期条目」的处理方式。

## 做了什么

1. 接手物料主数据模块的三个需求，其中两个涉及状态流转，前端加按钮、后端补接口。
2. 把原来散在定时任务里的三个接口改成串行编排，避免下游拿不到上游结果。
3. 补了两次线上问题的日志排查，都是入参字段为空导致的空指针。

## 教训

- 改状态机之前，先把所有调用方列出来，不然改完总有漏掉的入口。
- 前端展示的状态和后端存的枚举要对一份表，别靠猜。
- 需求文档里的「顺手改一下」往往是最花时间的部分，要单独评估。

## 下季度想改进

- 每个需求结束写一页复盘，记清楚为什么这么改，而不是只记改了什么。
- 把常用的排查 SQL 整理成一份清单，省得每次重写。
